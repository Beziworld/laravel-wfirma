# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 1.x     | Yes       |

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security problems.

Send a report to **biuro@beziworld.eu** with a description of the issue, the
affected version and, if possible, a minimal reproduction. You will receive an
acknowledgement within 3 business days. Confirmed issues are fixed in a patch
release and disclosed in the changelog once a fix is available.
